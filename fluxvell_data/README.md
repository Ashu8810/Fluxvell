# Fluxvell Website Documentation

This folder contains one Markdown document for every live leaf page listed in the provided Fluxvell architecture diagram and retrieved from `https://fluxvell.com/`, plus the homepage. It also contains a transcription of the supplied architecture diagram and a route-status note for the diagram's group routes and footer-only Blog reference.

| Set | Files | Count |
|---|---|---:|
| Homepage | `Home.md` | 1 |

The architecture diagram states a total of 24 public routes, while its displayed category counts add to 25. The documentation preserves that source discrepancy in `architecture.md` and `route-status.md` rather than resolving it with information from outside the provided sources.

## Source restriction

The page documents use only text retrieved from the specified Fluxvell website. The architecture and route-status documents use the attached `Fluxvell_og.pdf` together with live-site route checks. No external product, company, industry, or technical information has been added.
